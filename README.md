# くらしの在庫

食品や日用品の残りと期限を管理できるアプリです。在庫データは、この端末のブラウザに自動保存されます。

## 商品を登録する

1. 在庫一覧で「商品を登録」を押します。
2. 商品名を入力します。別名やタグを付けておくと、あとから探しやすくなります。
3. 手元に在庫があれば「初期在庫を一緒に登録する」を選び、数量と期限を入力します。
4. 「商品を登録」を押します。在庫がゼロの商品も登録できます。

## 在庫を増やす・減らす

在庫一覧で商品を選び、詳細画面を開きます。

- **買い足したとき**は「入庫する」を押し、数量と期限を入力して記録します。
- **使ったとき**は「出庫する」を押し、使った在庫と数量を選んで記録します。
- **記録を直すとき**は「入出庫の履歴」の該当行にある編集ボタンを押します。

一覧では商品名・別名で検索し、タグで絞り込めます。期限が近い在庫や期限切れの在庫は、一覧上部の「期限が近い在庫」で確認できます。

## バックアップする・復元する

1. 右上のメニューから「バックアップ連携する」を開きます。
2. **保存する場合**は「バックアップを保存」を押し、ダウンロードしたJSONファイルを保管します。
3. **復元する場合**は「バックアップから復元」を押し、保存したJSONファイルを選びます。ファイル名・日時・件数を確認してから確定します。

**復元すると、そのブラウザにある在庫データはファイルの内容に置き換わります。** 別の端末・ブラウザ・URLへ移るときは、移動前にバックアップを保存し、移動先で復元してください。端末間の自動同期はありません。

## スマホのホーム画面から使う

GitHub PagesなどのHTTPS配信先でアプリを開きます。iPhoneではSafariの共有メニューから「ホーム画面に追加」、AndroidではChromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

追加したアプリを通信できる状態で開き、メニューに「オフラインで起動・保存できます。」と表示されたら、通信がない場所でも起動して在庫を記録できます。スマホ向けのローカル確認用HTTPアドレスでは、オフライン起動は利用できません。

「新しい版に更新する」が表示されたら、開いているタブでの編集を終えてから押してください。
